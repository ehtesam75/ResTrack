📋 Privacy Policy – ResTrack

{# Effective Date #}

📅 Effective Date

January 23, 2026

{# Introduction #}

ResTrack is designed with privacy and data protection in mind. This Privacy Policy describes how information is collected, used, stored, and protected when using the ResTrack platform.

{# Information Collected #}

📊 1. Information Collected

Only information necessary for the proper functioning of the platform is collected.

Teacher Information:

  • • Name
  • • Username
  • • Institution name
  • • Email address
  • • Account-related activity

Student Information:

  • • Name
  • • Roll no.
  • • Class
  • • Exam participation records
  • • Point spent record
  • • Marks and evaluation details

Exam & Academic Data:

  • • Exam questions
  • • Marked Answer sheet
  • • Uploaded documents (such as PDF/RAR/ZIP)
  • • Exam results and reports

System Information

  • • Login session data
  • • Basic usage activity for security and monitoring
{# Purpose of Data Collection #}

🎯 2. Purpose of Data Collection

Collected data is used to:

  • • Manage exams and assessments
  • • Allow teachers to create students, subjects, and exams
  • • Store and display exam results and evaluations
  • • Ensure proper authentication and access control
  • • Maintain system stability and security

Personal data is not used for advertising, marketing, or tracking purposes.

{# Data Access & Visibility #}

👁️ 3. Data Access & Visibility

  • • Teachers can access only the data created by their own account
  • • Access to other teachers' data is strictly restricted
  • • Student information is visible only to the relevant teacher
  • • Administrative access is limited to system maintenance when required
{# Data Sharing #}

🚫 4. Data Sharing

ResTrack does not:

  • • Sell personal data
  • • Share data with third parties
  • • Transfer data to external organizations or services

All data remains within the ResTrack system.

{# Data Security #}

🔐 5. Data Security

Reasonable technical and organizational measures are applied to protect stored data, including:

  • • Secure authentication mechanisms
  • • Role-based access control
  • • Restricted database permissions

While appropriate precautions are taken, absolute security cannot be guaranteed.

{# Account & Data Deletion #}

🗑️ 6. Account & Data Deletion

Teachers may permanently delete their account.

Upon account deletion:

  • • All students created by that teacher
  • • All subjects, exams, exam records, point spent records and results
  • • All uploaded files and related data

are permanently and irreversibly removed from the system.

This action cannot be undone.

{# Educational Use Disclaimer #}

🎓 7. Educational Use Disclaimer

ResTrack is developed for educational and academic purposes. It may be used as a learning, demonstration, or internal assessment platform and should not be considered an official or government-certified examination system.

{# Policy Updates #}

🔄 8. Policy Updates

This Privacy Policy may be updated as the project evolves. Any changes will be reflected on this page with an updated effective date.

{# Contact Information #}

📧 9. Contact Information

For questions or concerns regarding this Privacy Policy, contact:
